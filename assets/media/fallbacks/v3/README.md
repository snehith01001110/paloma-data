# Paloma category symbols v3

This release replaces scene-heavy storefront concepts with one bold, generic
category symbol for each of Paloma's 16 active establishment types. The artwork
is designed for compact cards and 72-point list thumbnails: one central cue,
large flat shapes, strong contrast, and no venue-specific architecture.

The iOS establishment detail screen intentionally does not show these concepts.
It uses a pinned map header instead. The category art remains available for
cards, compact rows, and other small discovery surfaces.

Every source prompt is retained beside its reviewed 1600×1000 JPEG master.
Responsive hero, card, and thumbnail derivatives use content-addressed paths;
the app bundles the 960×600 card derivative so compact discovery never waits
for the network.

All artwork is a generic Paloma-owned concept and is not a depiction of any
specific establishment.
