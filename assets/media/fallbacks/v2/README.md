# Paloma category storefronts v2

This release replaces broad family repetition with one reviewed base illustration
for every active establishment type. Fifteen new assets live here; the existing
`category-billiards-bar` asset from v1 remains the sixteenth category cover.

All artwork is a generic Paloma-owned concept. It is not a photograph or a
representation of any specific establishment. Each scene uses recognizable,
type-level cues without business names, readable signs, logos, or trademarks.

The checked-in JPEGs are the reviewed 1600×1000 masters. The deterministic
media renderer emits 960×600 card and 320×200 thumbnail variants with stripped
metadata. Supabase object paths contain each output hash and are never
overwritten.

The generic v1 family assets remain as a safe fallback for any future type that
has not yet received a reviewed category illustration.
