# Paloma fallback storefronts v1

These five source-owned illustrations guarantee a useful cover for every
published establishment without a provider request. They are generic concepts,
not photographs or representations of any specific venue.

- `category-billiards-bar` overrides the general family for billiards bars.
- `family-spirits` covers cocktail bars, lounges, nightclubs, and distilleries.
- `family-wine` covers wine bars, wineries, and tasting rooms.
- `family-beer` covers breweries, taprooms, brewpubs, beer bars, pubs, dive
  bars, and sports bars.
- `family-other` covers generic bars and future types until a more specific
  family is reviewed.

The checked-in JPEG is the reviewed 1600×1000 master. The media renderer emits
960×600 card and 320×200 thumbnail variants with stripped metadata. Object
paths contain the output hash and are uploaded without overwrite with a
one-year immutable cache policy.
